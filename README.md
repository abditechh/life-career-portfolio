# Abdi Abdirashid · Personal archive

A bilingual German/English personal life-and-career portfolio, built as a growing digital archive.

## Website

https://abditechh.github.io/life-career-portfolio/

## Included

- Employment history and education from the existing CVs.
- Basketball and cycling.
- One combined drone and creative-project entry, including A1/A3 and A2 qualifications.
- A project detail page whose return link stays in this archive.
- Pestalozzi intercultural exchange participation, 10–22 July 2017.
- German and English CVs with browser editing, HTML export and A4 printing.
- An optional browser-local document collection.

## Privacy

No private certificates, employment references or signed documents are included. The Pestalozzi certificate is kept separately. Files added to the document collection stay in the user's browser using IndexedDB; they are not uploaded to GitHub or a server. This is not an encrypted vault or a backup. People using the same browser profile, and scripts on the same origin, can access local browser storage. Keep originals and backups separately.

The public CV copies omit the home address, phone number, email, permit details and job-search availability.

## Hosting and editing

This is a static website with no dependencies or build step. GitHub Pages serves `main` at the repository root. Keep `assets/` and `cv/` alongside `index.html`. The `.nojekyll` file disables Jekyll processing.

For a local preview, run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory and open `http://127.0.0.1:8765/`.

The CV print buttons use the browser print dialog: choose A4, 100% scale and disable headers/footers. Edits made inside a CV in the browser do not update this repository automatically.

## Content sources

Career facts were taken from the previously created CVs. The user confirmed their hobbies and drone qualifications. Pestalozzi dates and project information were checked against the user's attendance certificate. No project leadership, sporting achievements or employment details were inferred.

The project detail page retains the user's existing public drone video, gallery and hobby images. It is included here so navigation remains within this personal archive.
